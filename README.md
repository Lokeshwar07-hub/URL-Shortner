# URL Shortener 🔗

A simple and efficient URL Shortener web application built using **Node.js, Express.js, MongoDB, and EJS** that converts long URLs into short links and redirects users to the original URL.

## Features ✨
- Shorten long URLs
- Redirect shortened URLs to original links
- User authentication (Login / Signup)
- Database storage using MongoDB
- Simple and responsive UI

## Tech Stack 🛠️
### Frontend
- EJS
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
